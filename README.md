## Sprint 2

### Objetivo

Incorporar una base de datos relacional utilizando SQLAlchemy
y consultar una API externa para obtener cotizaciones del dólar.

### Introducción y contexto

Este sprint continúa el desarrollo realizado en Sprint_1.
Se migrarán los datos de los archivos CSV a la base de datos
y se adaptarán los repositorios para trabajar con ella.
También se incorporarán consultas a la API del dólar y
reportes de precios en distintas monedas.
